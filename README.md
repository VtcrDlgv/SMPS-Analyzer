# SMPS Analyzer 14.1

Усреднение и сравнение спектров размеров аэрозольных частиц по экспортным файлам SMPS
(TSI Aerosol Instrument Manager, текст с запятой или табуляцией). Несколько файлов объединяются в проект.

## Сборка

**Windows — портативный exe.** Установить Python 3.9+ с python.org (оставить галочку «tcl/tk and IDLE»),
запустить `build_windows.bat`. Результат — `dist\SMPS_Analyzer.exe`; установка не нужна, файл можно копировать.
Первый запуск 5–10 с (exe распаковывается во временную папку). Файл не подписан: SmartScreen может показать
«Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

**macOS.** `./build_mac.sh` → `dist/SMPS Analyzer.app`. Нужен Python с python.org. Первый запуск — правый клик → «Открыть».

**Без сборки:** `pip install -r requirements.txt`, затем `python smps_analyzer.py [файлы или проект]`.

### Текст «О программе»

Правится в `about.txt` перед сборкой (`{version}` заменяется номером версии). При запуске из исходников
изменения видны сразу. При сборке `SMPS_Analyzer.spec` создаёт из него модуль `about_builtin.py` и вшивает
в программу: выпущенная программа показывает только вшитый текст.

## Работа

1. **Выберите файл** (или «Файл → Открыть файл»; можно сразу несколько). Каждый файл — вкладка внизу окна.
2. Группы сразу раскладываются по паузам между запусками («Авто»). Поправьте их в зоне «Группы для усреднения».
3. **Построить** — сводный график и графики групп. Дальше кнопка называется **Перестроить**: сплошная
   фиолетовая — есть непримененные изменения (что именно — в подсказке), с рамкой — графики актуальны.
4. «Файл → Сохранить проект» — всё вместе с копиями исходных файлов в один архив `.smpsa`. Сохранение идёт
   в фоне; если закрыть программу во время сохранения, она закроется после его окончания (при ошибке — останется
   открытой). При открытии проекта построенные графики строятся сразу: текущая вкладка первой, остальные в фоне.

Программа открывается развёрнутой на весь экран. Справа в строке вкладок во время построения графиков,
сохранения проекта и экспорта появляется прогресс; в остальное время его нет.

графики — по «Перестроить».

### Вкладки

До 16 файлов. «+» — новая пустая вкладка. × — удалить файл из проекта (с диска он не удаляется).
Уже открытый файл можно открыть ещё раз — новая вкладка называется «имя (1).txt», «имя (2).txt»…; это имя
используется в графиках, таблицах, сравнении, экспорте и сохраняется в проекте.

### Панель групп

- **Авто** — новая группа после паузы (интервал > длительность семпла + 10 с; длительность — из файла).
- **По 1 / 5 / 10 / N** — по N семплов подряд от первого. N меняется кнопками − / + или вводом — сразу.
- **Ручной выбор** — все семплы вне групп; группы протягиваются мышью.
- **Показать:** карта (малые размеры сверху), Scan status (зелёный — Normal Scan, красный — другой статус;
  в подсказке текст статуса), полоса параметра по семплам, кривые всех семплов, превью.
- Красные линии на карте — границы ограниченного диапазона: тянуть мышью (прилипают к границам каналов),
  двойной щелчок по красному числу — ввести значение (остаётся как введено; в расчёт — каналы, целиком
  лежащие в диапазоне).
- Полоска ═ под картой, «Кривыми» и превью — изменить высоту.

| Действие | Windows / Linux | macOS |
|---|---|---|
| Исключить / включить семпл | ЛКМ | клик |
| Объединить протягиванием | ЛКМ + протянуть | клик + протянуть |
| Объединить всё между выделенным и кликнутым | Shift + ЛКМ | Shift + клик |
| Перевести выделение | ← / → | ← / → |
| Группа +1 семпл наружу / −1 внутрь | Shift + ← / → | Shift + ← / → |
| Исключить / включить выделенный | Пробел | Пробел |

| График семпла в превью | ПКМ | ПКМ, Ctrl + клик |
| Название группы | 2× ЛКМ по номеру | двойной клик по номеру |
| Масштаб / прокрутка ряда | Ctrl + колесо / Shift + колесо | ⌘ + колесо / Shift + колесо |

### Расчёты

Статистики (N, среднее, медиана, геом. среднее, GSD, мода) считаются по усреднённому спектру в выбранном
диапазоне на точной логарифмической сетке каналов прибора (Channels/Decade); на полном диапазоне совпадают
с величинами AIM в пределах 0,02 %. Сводная таблица содержит и расчётные значения, и средние значения
прибора по всему диапазону. Логнормальная аппроксимация — 1–3 моды по dN/dlogDp, Левенберг–Марквардт,
погрешности из ковариационной матрицы.

### Экспорт

- CSV: «Размер, нм» + по столбцу на группу (заголовок — название группы), только каналы в диапазоне,
  6 значащих цифр, UTF-8 с BOM — Origin и Excel открывают без настройки. Если в сравнении у файлов разные
  каналы — пары столбцов X/Y.
- **Сводная таблица** — книга Excel (.xlsx) для текущего файла или всех файлов проекта. Листы: «Спектры»
  (данные графиков), «Расчёт в диапазоне», «По данным прибора (весь диап.)», «Аппроксимация» (если включена),
  «Сведения», «Графики» (диаграммы Excel по ячейкам книги: сводная по файлу и по группе, по две в ряд; линии
  статистик — отдельными рядами по настройке, общая концентрация — в заголовке, лог. оси — как у графика) и
  «Данные графиков» (точки линий статистик и кривых аппроксимации).
- PNG — 1600 px шириной. У каждого графика — «Сохранить PNG», «Сохранить CSV», «Шкала» и «Открыть крупно»
  (интерактивное окно со своим меню «Анализ», действующим только на этот график, и кнопкой «Шкала»).
- «Шкала» — логарифмические оси X (размер) и/или Y (концентрация) для одного графика; применяется сразу,
  сохраняется при «Перестроить» и в проекте. Шкала из крупного окна меняется и у плитки, и наоборот.
- «Интеграл в диапазоне» — число частиц N, поверхность S и объём V в заданном интервале и их доли.

### Формат проекта `.smpsa`

Обычный ZIP: `project.json` (группы по номерам семплов, названия, исключения, диапазоны, аппроксимация,
настройки вида) и `data/…` — исходные файлы прибора байт в байт с контрольной суммой SHA-256. Сохранение
атомарное (временный файл → подмена). Если исходный файл на диске изменился после сохранения — запись в журнале.
